About the algorithm (yescrypt)

MateableCoin is multi-algorithm: every block is mined with one of five PoW algorithms (scrypt, yescrypt, whirlpool, ghostrider, balloon), chosen block by block and signalled in the block version. This pool always requests and builds yescrypt blocks specifically -- branded yescryptr8 (N=2048, r=8, p=1, self-salted) -- over the 80-byte block header. The pool speaks the standard Bitcoin Stratum protocol. Yescrypt blocks target about 2.5 minutes apart; the whole coinbase (subsidy + fees) goes to miners, there is no masternode or dev-fee cut in the coinbase.

  • Use poolpayminer (below): it knows yescryptr8 and speaks this pool's protocol.
  • yescrypt is a CPU algorithm; any modern CPU works.
  • MTBC also has a separate hybrid Proof-of-Stake system (Particl PoSv3) -- irrelevant to mining, this pool only builds PoW blocks.

Software

  • poolpayminer (Windows x64 and Linux x86-64): downloads, source code. A modified XMRig with yescrypt (yescryptr8) and TLS support. Fee 1% (1 minute in about 100), shown at start-up; details on the download page.
  • Wallet (to get your address): MateableCoin Core from the project (releases).

Rewards and payments

  • Reward scheme: proportional with time weighting (older shares of a round weigh less).
  • Block rewards become spendable after 60 blocks (the network's coinbase maturity, roughly an hour); the pool credits your balance after that.
  • Payments are ordinary MTBC transactions to your address. Everyone who is due is paid in one transaction per round, the network fee is shared by the paid miners.
  • Modes: prop:ADDRESS (shared reward, default) or solo:ADDRESS (the block finder takes the reward).

Об алгоритме (yescrypt)

MateableCoin — мультиалгоритменная монета: каждый блок майнится одним из пяти алгоритмов PoW (scrypt, yescrypt, whirlpool, ghostrider, balloon), выбираемым для каждого блока и обозначаемым в версии блока. Этот пул всегда запрашивает и собирает блоки yescrypt — под маркой yescryptr8 (N=2048, r=8, p=1, самосолёный) — над 80-байтным заголовком блока. Пул работает по стандартному протоколу Bitcoin Stratum. Блоки yescrypt находятся в среднем раз в ~2.5 минуты; весь coinbase (награда + комиссии) достаётся майнерам, отчислений мастернодам или разработчикам в coinbase нет.

  • Используйте poolpayminer (ниже): он знает yescryptr8 и работает по протоколу этого пула.
  • yescrypt это процессорный алгоритм; подойдёт любой современный процессор.
  • У MTBC также есть отдельная гибридная система Proof-of-Stake (Particl PoSv3) — к майнингу отношения не имеет, пул собирает только PoW-блоки.

Программы

  • poolpayminer (Windows x64 и Linux x86-64): загрузки, исходный код. Изменённый XMRig с yescrypt (yescryptr8) и поддержкой TLS. Комиссия 1% (1 минута из примерно 100), показывается при запуске; подробности на странице загрузок.
  • Кошелёк (чтобы получить адрес): MateableCoin Core от проекта (релизы).

Награды и выплаты

  • Схема наград: пропорциональная с учётом времени (старые шары раунда весят меньше).
  • Награда за блок становится доступной через 60 блоков (примерно через час); после этого пул зачисляет её на ваш баланс.
  • Выплаты это обычные транзакции MTBC на ваш адрес. Все, кому пора платить, получают деньги одной транзакцией за раунд, комиссию сети делят между собой получатели.
  • Режимы: prop:АДРЕС (общая награда, по умолчанию) или solo:АДРЕС (награду забирает нашедший блок).
